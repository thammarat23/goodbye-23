# Jotdee — เฟส 0: ทดสอบจุดเสี่ยงทางเทคนิค

แอปทดสอบนี้ตอบคำถามจากหัวข้อ "จุดเสี่ยงทางเทคนิคที่ต้องทดสอบก่อน" ใน Jotdee Master Design v2
ว่ามือถือจริงทำสิ่งที่ Jotdee ต้องการได้หรือไม่ ก่อนลงแรงสร้างแอปเต็ม

## โครงสร้าง

| โฟลเดอร์ | คืออะไร |
| --- | --- |
| `core/` | โค้ด Kotlin ล้วน ใช้ซ้ำในแอปจริงได้: อ่านวันเวลาภาษาไทย, ตรวจเลขบัตรประชาชน, หายอดรวมใบเสร็จ, โน้ตตัวอย่างสำหรับทดสอบค้นหา |
| `app/` | แอป Android ทดสอบ 4 แท็บ: OCR ไทย, เตือน, ค้นหา, วันเวลา |
| `.github/workflows/build.yml` | GitHub Actions รันทดสอบ `core` และ build ไฟล์ติดตั้ง APK ทุกครั้งที่ push |

## ดาวน์โหลดไฟล์ติดตั้ง (ไม่ต้องมี Android Studio)

1. เปิดแท็บ **Actions** ของ repo นี้ แล้วเลือกรอบ build ล่าสุดที่เป็นสีเขียว
2. เลื่อนลงไปที่ **Artifacts** แล้วดาวน์โหลด `jotdee-spike-apk`
3. แตกไฟล์ zip แล้วส่ง `app-debug.apk` เข้ามือถือ กดติดตั้ง (ต้องอนุญาต "ติดตั้งแอปที่ไม่รู้จัก")

## วิธีทดสอบและเกณฑ์ผ่าน

| แท็บ | ทำอย่างไร | ผ่านเมื่อ |
| --- | --- | --- |
| OCR ไทย | ถ่ายใบเสร็จ 20 ใบและบัตรประชาชน 10 ใบ (ปิดชื่อได้) แล้วเลือกรูปทีละใบ ลองทั้งโมเดล fast และ best | ยอดรวมถูก ≥ 18/20 ใบ และพบเลขบัตรถูกต้อง ≥ 9/10 ใบ |
| เตือน | กดเริ่มทดสอบ 16 ครั้ง ห่างกัน 30 นาที ตอนก่อนนอน วางเครื่องปิดจอทั้งคืน เช้ามากด "รีเฟรชผล" ทำบนทุกยี่ห้อที่มี | ดังครบทุกครั้ง และช้าไม่เกิน 60 วินาที |
| ค้นหา | กด "สร้างโน้ตตัวอย่าง" แล้วค้น ประกันรถ, ค่าไฟ, เอกสาร, แอร์ | FTS5 เจอเท่ากับ LIKE และใช้เวลา < 200 ms |
| วันเวลา | พิมพ์หรือพูดผ่านไมค์คีย์บอร์ด เช่น "พรุ่งนี้บ่ายสอง", "สองทุ่มครึ่ง", "ทุกวันที่ 5" | แปลถูก ≥ 9 ใน 10 ประโยคที่พูดจริงในชีวิตประจำวัน |

จดผลลงในตารางนี้แล้วส่งกลับมา เพื่อตัดสินใจว่าต้องปรับดีไซน์ตรงไหนก่อนเริ่มเวอร์ชัน 1.0

## ผลที่รู้แล้วจากการทดสอบในคอมพิวเตอร์

- **ค้นหาภาษาไทย:** FTS5 trigram ค้นโน้ต 10,000 ใบได้ใน 1–3 ms และเจอครบเท่ากับ LIKE
  แต่คำที่สั้นกว่า 3 ตัวอักษร (เช่น "รถ") ค้นด้วย trigram ไม่ได้ แอปจึงสลับไปใช้ LIKE ให้อัตโนมัติ
- **อ่านวันเวลาภาษาไทย:** รองรับ บ่าย/ทุ่ม/ตี/โมงเช้า/โมงเย็น, ครึ่ง, นาที, เลขไทย, วันในสัปดาห์, "หน้า",
  ชื่อเดือนเต็มและย่อ, ทุกวัน/สัปดาห์/เดือน/ปี/วันที่ N, "อีก N นาที" และ "เตือนก่อน …"
  "N โมง" ที่ไม่มีคำว่าเช้า/เย็น นับแบบดั้งเดิม ("สองโมง" = 08:00) และแอปต้องให้ผู้ใช้ยืนยันเสมอ

## รันในคอมพิวเตอร์

```bash
./gradlew :core:test            # ทดสอบ core
./gradlew :app:assembleDebug    # build แอป (ต้องมี Android SDK)
./gradlew -PcoreOnly :core:test # เครื่องที่ไม่มี Android SDK
```
