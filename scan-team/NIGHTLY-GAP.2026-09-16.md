## วิธีเช็คและแก้ (ที่เครื่องบ้าน)

เช็คก่อนว่าหลับจริงไหม:

```bat
powercfg /lastwake
powercfg /requests
```

ถ้าใช่ ปิดการหลับตอนเสียบปลั๊ก:

```bat
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /change disk-timeout-ac 0
powercfg /change monitor-timeout-ac 20
```

(จอดับได้ 20 นาที ไม่เป็นไร แต่เครื่องต้องไม่หลับ)
