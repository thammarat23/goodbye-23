# ระบบสแกนหนังสือกำลังภายใน — เครื่องที่สอง

ไปป์ไลน์ OCR ภาษาไทยสำหรับหนังสือกำลังภายใน รันบน Ubuntu/Linux
ใช้ชื่อโฟลเดอร์เดียวกับระบบเดิมบนไดรฟ์ จึงสลับไปมาระหว่างเครื่องหลักกับ
เครื่องที่สองได้โดยไม่ต้องแก้อะไร

## ติดตั้ง (เครื่องเปล่า)

```bash
bash scan/setup.sh
```

ติดตั้ง tesseract (ไทย/อังกฤษ/จีน), poppler, ghostscript, ocrmypdf, unpaper
และไลบรารี Python ทั้งหมด จบแล้วจะตรวจความพร้อมให้อัตโนมัติ

ตรวจความพร้อมเมื่อไรก็ได้:

```bash
python3 scan/scan_books.py --check
```

## ใช้งาน

```bash
# วางไฟล์ไว้ที่ work/scan_inbox/ แล้วสั่งรอบเดียว
python3 scan/scan_books.py

# สร้าง PDF ที่ค้นหาข้อความได้ด้วย
python3 scan/scan_books.py --pdf

# ระบุไฟล์เอง (อยู่ที่ไหนก็ได้)
python3 scan/scan_books.py --pdf ~/หนังสือ/เล่ม1.pdf

# เฝ้าโฟลเดอร์ตลอด วางไฟล์เมื่อไรก็สแกนให้
python3 scan/scan_books.py --watch
```

รองรับ `.pdf` และรูป `.png .jpg .jpeg .tif .tiff .bmp .webp`

## โฟลเดอร์ทำงาน (`work/`)

| โฟลเดอร์ | ใช้ทำอะไร |
|---|---|
| `scan_inbox` | วางไฟล์ที่จะสแกน |
| `scan_processing` | ไฟล์ที่กำลังทำอยู่ |
| `scan_text` | **ผลงาน** — `.txt` `.raw.txt` `.json` `.ocr.pdf` |
| `scan_done` | ต้นฉบับที่สแกนเสร็จแล้ว |
| `scan_failed` | ไฟล์ที่สแกนไม่ผ่าน |
| `logs/scanner.log` | ประวัติการทำงาน |

ผลงานแต่ละเล่มได้สี่ไฟล์:

- `<เวลา>_<ชื่อ>.txt` — ข้อความที่ทำความสะอาดแล้ว (ตัวหลักที่เอาไปใช้)
- `<เวลา>_<ชื่อ>.raw.txt` — ข้อความดิบจาก OCR ไว้เทียบเวลาสงสัยว่าคลีนกินเนื้อหา
- `<เวลา>_<ชื่อ>.json` — จำนวนหน้า จำนวนอักขระ เวลาที่ใช้
- `<เวลา>_<ชื่อ>.ocr.pdf` — PDF ค้นหาข้อความได้ (เฉพาะเมื่อใส่ `--pdf`)

## ปรับแต่ง

ตั้งผ่าน environment variable:

| ตัวแปร | ค่าตั้งต้น | ความหมาย |
|---|---|---|
| `BOOK_SCAN_LANG` | `tha+eng` | ภาษา OCR (มี `chi_sim` `chi_tra` ให้ด้วย) |
| `BOOK_SCAN_DPI` | `300` | ความละเอียดตอนแปลง PDF เป็นภาพ |
| `BOOK_SCAN_POLL_SECONDS` | `10` | รอบการตรวจโฟลเดอร์ตอน `--watch` |
| `BOOK_SCAN_ROOT` | `work/` | ที่ตั้งโฟลเดอร์ทำงาน |
| `BOOK_SCAN_TESSERACT` | ตรวจหาเอง | พาธ tesseract |

เล่มที่ตัวอักษรเล็กหรือกระดาษเหลืองมาก ลอง `BOOK_SCAN_DPI=400`

## การทำความสะอาดข้อความไทย

`thai_clean.py` ใช้แยกเดี่ยวกับไฟล์ `.txt` ที่มีอยู่แล้วได้:

```bash
python3 scan/thai_clean.py ไฟล์.txt              # ได้ ไฟล์.clean.txt
python3 scan/thai_clean.py ไฟล์.txt --in-place   # ทับไฟล์เดิม
```

สิ่งที่ตัวคลีนทำ:

- ยุบวรรณยุกต์ที่ OCR อ่านซ้อนกัน (`เ่จ้่า` → `เจ้า`)
- ตัดอักษรละตินโดดๆ ที่ลอยกลางข้อความไทย
- ตัดโทเคนขยะที่ Tesseract มักหลุดมากับหนังสือพิมพ์เก่า
- ตัดบรรทัดที่ไม่มีคำจริง (ต้องมีอักษรไทยหรืออังกฤษติดกัน 3 ตัวขึ้นไป)
- จัดเว้นบรรทัดรอบตัวคั่นหน้า

**ตัวคลีนไม่แตะเครื่องหมายคำพูด** `"` `'` เพราะบทสนทนาในนิยายใช้ตลอด
ถ้าสงสัยว่าคลีนกินเนื้อหา เทียบกับ `.raw.txt` ได้เสมอ

## ความเร็ว

เครื่องที่สอง (4 คอร์) OCR ได้ราว 2 วินาทีต่อหน้าที่ 300 DPI ทำขนาน 4 หน้าพร้อมกัน
หน้าที่มี text layer อยู่แล้วจะข้าม OCR ไปเลย เล่มที่เป็น PDF ข้อความอยู่แล้วจึงเร็วมาก

## ต่างจากระบบเดิมบนไดรฟ์อย่างไร

ระบบเดิม (`scan_books.py` เวอร์ชัน Windows) ฮาร์ดโค้ดพาธ
`C:\Program Files\Tesseract-OCR` และพาธ poppler ไว้ ใช้บนเครื่องที่สองไม่ได้
เวอร์ชันนี้:

- ตรวจหาที่ตั้งเครื่องมือเอง ใช้ได้ทั้ง Linux และ Windows
- ใช้ PyMuPDF แทน poppler ตอนแปลงหน้า ไม่ต้องพึ่ง binary ภายนอก
- ข้าม OCR หน้าที่มี text layer อยู่แล้ว
- เก็บ `.raw.txt` ไว้เทียบด้วย
- สร้าง PDF ที่ค้นหาข้อความได้
- แก้บั๊กชื่อไฟล์ภาษาไทยกลายเป็น `_` (`เซียวเฮ้ง` → `เซ_ยวเฮ_ง`)
- แก้ตัวคลีนกินเครื่องหมายคำพูดในบทสนทนา
