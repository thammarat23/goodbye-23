# สถานะงาน — อ่านไฟล์นี้ก่อนเริ่มแชตใหม่

เขียนไว้เพื่อให้แชตใหม่ไม่ต้องไปไล่สำรวจไดรฟ์ซ้ำ ซึ่งเป็นตัวกินเครดิตที่ใหญ่
ที่สุดในงานนี้ ข้อเท็จจริงทั้งหมดที่หามาแล้วอยู่ในไฟล์นี้

## เครื่องมือทำเสร็จหมดแล้ว ไม่ต้องแก้อะไรเพิ่ม

| สคริปต์ | ทำอะไร |
|---|---|
| `survey_pdfs.py` | สำรวจว่าเล่มไหนมี text layer เล่มไหนต้อง OCR |
| `make_book.py` | เตรียมหนังสือ 1 เล่ม แบ่งตอน แบ่งย่อหน้า ออก manifest เสียง |
| `scan_books.py` | OCR (batch / watch / `--pdf` / `--check`) |
| `repair_all.py` | ซ่อมข้อความทั้งโฟลเดอร์ ขนานตามคอร์ สรุปเป็น CSV |
| `fix_ocr_text.py` | ซ่อมทีละไฟล์ |
| `thai_repair.py` | ตรรกะซ่อมคำด้วยพจนานุกรม |
| `thai_space.py` | แทรกช่องว่างคืน (ต้องสั่ง `--space` เอง) |

วัดผลแล้วที่ 20,000 บรรทัด สามชุดข้อมูล — กู้คืน 86% · ทำของพัง 0.4% ·
ชื่อตัวละครรอด 99% รายละเอียดอยู่ใน `README.md`

## ข้อเท็จจริงที่หามาแล้ว อย่าไปหาซ้ำ

- **เครื่องที่สอง** RAM 15 GB · 4 คอร์ · OCR ได้ 0.5 วินาที/หน้า
- **ดึงไฟล์จาก Google Drive มาเครื่องที่สองไม่ได้** พร็อกซีบล็อก
  `drive.google.com` ตามนโยบายองค์กร และ API ส่งกลับเป็น base64 ที่ใหญ่เกิน
  รับไหว **ช่องทางเดียวคือ git** ดู `HANDOFF.md`
- **บนเครื่องหลักต้องใช้ `py -3` ไม่ใช่ `python`** เพราะ `python` ชี้ไป venv
  ของโปรแกรมอื่น (`hermes-agent`) ที่ไม่มี pip · pymupdf ติดตั้งไว้แล้ว
- **คลังหนังสือมี PDF 2,742 เล่ม** ในโฟลเดอร์ `หนังสือกำลังภายใน`
- **กอง "หนังสือรอแก้" มี 100 ไฟล์** เป็น `.txt` ที่ OCR แล้วแต่ข้อความเสีย
- **ต้นฉบับ PDF ของกองที่เสียยังอยู่ครบ** เช่น จอมกะล่อนราชวงศ์ถัง เล่ม 01-22,
  จอมคนแผ่นดินเดือด เล่ม 3-23, จอมดาบทักษิณ เล่ม 1-3
- **คิวเสียงเคยเดินอยู่** 470 รายการ ทำไป 196 และมีอย่างน้อย 18 เล่มที่ทำเสียง
  จากข้อความที่ยังเสีย ต้องทำใหม่หลังแก้ข้อความ
- **ขนาดไฟล์บอกอะไรได้** เล่มในชุดเดียวกันมีทั้ง 5 MB และ 106 MB
  เล่มเล็กน่าจะเป็น PDF ข้อความอยู่แล้ว เล่มใหญ่คือภาพสแกน

## ขั้นต่อไป

**1. รู้ว่าเล่มไหนไม่ต้อง OCR** (ทำบนเครื่องหลัก ยังไม่ได้ผล)

```powershell
py -3 -X utf8 tools\scan\survey_pdfs.py "G:\ไดรฟ์ของฉัน\หนังสือกำลังภายใน" --recursive --quick 6
```

หยุดกลางคันแล้วรันซ้ำได้ ทำต่อจากเดิม ผลอยู่ใน `สำรวจPDF.csv`

**2. เล่มที่มี text layer** ดึงข้อความบนเครื่องหลักได้เลย ไม่ต้อง OCR ไม่ต้องซ่อม

```powershell
py -3 -X utf8 tools\scan\make_book.py "<พาธเล่ม>"
```

**3. เล่มที่เป็นภาพสแกน** ส่งเข้า `inbox/` ให้เครื่องที่สอง OCR

## วิธีทำงานให้ไม่เปลืองเครดิต

สิ่งที่แพงคือ "ให้ผมอ่านหรือคิด" สิ่งที่ถูกคือ "ให้เครื่องรัน"

- **รันสคริปต์เองแล้วส่งมาแค่บรรทัดสรุป** อย่าวางผลยาวๆ ทั้งก้อน
- **อย่าให้ผมไล่ค้นไดรฟ์** ครั้งหนึ่งกินหลายหมื่นคำ ข้อมูลที่หามาแล้วอยู่ข้างบน
- **อย่าให้ผมอ่านไฟล์หนังสือทั้งไฟล์** ถ้าจะให้ตรวจ ให้ผมเขียนสคริปต์สรุป
  สถิติแทนการอ่านทีละบรรทัด
- **การ OCR และการซ่อมไม่กินเครดิตเลย** เป็นสคริปต์ที่รันในเครื่อง
  100 เล่มหรือ 10,000 เล่มก็เท่ากัน
- **เปิดแชตใหม่ให้บอกว่า "อ่าน scan/STATUS.md ก่อน"** จะได้ไม่ต้องเล่าใหม่
